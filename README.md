# Forno a Legna — Neapolitan Pizza Oven

A cooking game set in a tiny Neapolitan pizzeria built around a roaring
wood-fired oven. Guest tickets land on the order board; you stretch the
dough, lay the sauce and toppings on the assembly board, slide the pizza
into the 450°C oven and watch the **crust meter** — pull it out in the
golden window for a perfect leopard-spotted crust, too early and it is
pale, too late and it burns. Serve from the pass before your guests lose
patience: three walk-outs end the shift, and the rush only gets faster.

## How to play

- **Click an ingredient** on the counter (or press `1`–`0`) to add it to
  the pizza on the assembly board. Dough always goes down first.
- **Click the oven** to slide the pizza in; click it again to pull the
  pizza out onto the pass. Watch the crust meter needle.
- **Click a baked pizza** on the pass, then **click its ticket** on the
  order board to serve (or press `Space` to serve the first match).
- `Backspace` bins the selected pass pizza or wipes the board; `O` works
  the oven; `R` restarts after the shift ends.
- Coins: menu price + speed tip + perfect-crust bonus. Burnt pizzas earn
  nothing — bin them.

## Run it

Open `game/index.html` in a desktop browser, or serve the folder with
any static file server. No build step, no network, no dependencies.
